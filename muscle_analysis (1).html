CT 이미지를 불러오세요근육 경계에 점을 찍어 영역을 만듭니다.
영상에 실제 길이를 아는 기준선이 있다면 면적을 cm²로 환산할 수 있습니다.
1. 이미지 열기 → 2. 길이 보정 → 3. 포함·제외 영역 표시 → 4. 결과 저장

사용 방법

  1. 이미지 열기: 분석할 캡처 이미지를 선택합니다. 영상은 이 브라우저 안에서 처리됩니다.
  2. 길이 보정: 실제 길이가 알려진 기준선의 두 끝을 찍고 오른쪽에 길이(mm)를 입력합니다. 기준 길이를 모르면 픽셀 면적만 표시합니다.
  3. 포함 영역: 근육 경계를 따라 점을 찍고 ‘영역 완료’를 누릅니다. 여러 영역을 추가할 수 있습니다.
  4. 제외 영역: 뼈·골수 등 제외할 부분을 둘러싸고 완료합니다. 겹친 포함 영역은 한 번만 계산하고, 제외 영역은 포함 영역 안에서만 차감합니다.
  5. 저장: 측정값은 CSV, 이미지·경계·보정 정보는 작업 JSON, 표시 화면은 PNG로 저장합니다. JSON 파일로 작업을 다시 열 수 있습니다.

윤곽선으로 둘러싼 면적은 내부 지방 등을 포함할 수 있습니다. ‘근육만의 면적’으로 해석하려면 전문가가 정의한 기준으로 영역을 확인해야 합니다. 그림에 적힌 8,850 mm²는 이 웹의 자동 측정값으로 사용하지 않습니다.

단축키: Enter 영역 완료 · Backspace 마지막 점 취소 · Esc 현재 그리기 취소. 확대 후 이동은 화면 스크롤을 사용하세요.
